## Labs and assignments

Each session's lab is done after class to practise that day's ideas. It is not submitted or graded, and its solution is released afterwards. Keep your `.sql` files from each session: Assignment 1 (SQL), issued on D09, asks you to choose from them. The assignment has its own brief and deadline.
